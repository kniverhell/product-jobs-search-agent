# Mode: Tailor

Only for roles scoring 4.0+. If you ask for a lower-scored role, do it, but say once that the evaluation flagged it.

1. Read the JD, `00-master-resume.md`, `06-proof-points.md`, the evaluation report, and `01-target-roles.md`.
2. **Write down the JD's top six requirements in priority order before drafting.** That's the target. Show them at the top of the output file.
3. Draft to `tailored/YYYY-MM-DD-company-slug.md`:

## Rules

- **Reorder and re-weight only.** Every bullet traces to a line in the master resume. No new claims, no new numbers, no combining two accomplishments into one bigger-sounding one.
- Lead the Profile with the two or three requirements you genuinely hit hardest. Rewrite it fully for each role — the Profile is the highest-leverage paragraph and a generic one wastes it.
- Reorder the Capabilities line so the JD's vocabulary appears first. Mirror their terms *where your experience actually matches* — if they say "identity orchestration," use it; if they say "passwordless" and you've done architecture but not shipped it, don't imply you shipped it.
- Promote the archetype's proof points from `01-target-roles.md` into the top third of each role's bullets.
- Trim to two pages. Earlier Experience, Education, and Certifications compress first. Never cut a bullet that answers a top-six requirement.
- **Enforce all standing constraints in `06-proof-points.md`.** These are claims you must never make. Check every bullet against them before finishing.
- **`[TK]` placeholders never get filled, estimated, or dodged.** If a top-six requirement is best answered by a bullet whose number is TK, surface it at the top of the file: "This role wants X. Your strongest evidence is Y, but the number is still missing — worth getting before you send."
- **Order the Profile by how long you've held the evidence, not by what's fashionable.** Lead with the longest-proven skill; a newer one (AI, say) comes second, framed as the current extension. Read the order from the *Held since* column in `06-proof-points.md` → *Skills by tenure*, so every version follows the same order; if a skill isn't there yet, add it before drafting. *Failure: a profile draft opened with a one-year skill ahead of an eight-year one; it read as misleading.*
- **A delivered document is frozen.** Once a resume or letter has been handed over, suggest changes as exact wording in chat; don't edit the file or re-send it. Drafts before delivery can be edited freely. *Failure: repeated edits and re-sent files made so many copies that the current one got lost.*
- Keep it ATS-plain: no tables, no columns, no text in graphics, standard section headers.

## Then, in the same file

- **Gap memo** — what they want that you can't evidence, and how to answer it in a room. Not spin: an honest bridge, usually "here's the adjacent thing I did and why it transfers."
- **Screening question prep** — the three questions this JD implies a recruiter will ask, and your answers.

4. Update the tracker to `Tailored` with today's date in `last_touch` and `Send it` as `next_action`.
